# BELTCORE Model Assets

This folder stores model configuration and generated artifacts.

## Expected outputs

- best.pt
- last.pt
- metrics.json
- confusion_matrix.png
- results.png
- training_summary.json

## Dataset configuration

The generated `dataset.yaml` is based on the actual classes found in the raw dataset folders. This repository intentionally keeps the original SIH source data separate from any processed/training data.
